# ADR 0001：数据范围与来源

- 状态：已接受
- 日期：2026-09-09

## 决策

领域模型支持 Bangumi 全部作品类型；首批同步动画、游戏、角色、人物及其完整关系。

官方 Bangumi Archive 负责周期性全量基线，Bangumi v0 API 负责近期候选发现、热点实体刷新和详情校验。搜索接口只负责发现候选，实体和关系详情才可覆盖当前真值。

角色收藏数等上游热度以带 `provider`、`metric` 和来源时间的当前值保存。角色—作品关系必须保留主角、配角和客串，不能压平为作品 ID 数组。

## 原因

这能覆盖 Wife 的动画和游戏需求，同时避免把数据服务限制为 Wife 专用目录。Archive 降低全量采集压力，v0 API 弥补周快照的及时性。
