# ADR 0002：单后端与当前快照存储

- 状态：已接受
- 日期：2026-09-09

## 决策

只部署一个 Kotlin/Ktor 后端进程。该进程同时运行查询 API、定时 Archive 同步、v0 热数据刷新和手动同步入口，不部署独立 worker。

PostgreSQL 使用规范化实体与关系表。全量导入写入新数据代，校验成功后事务切换活动代；旧代仅为安全切换短暂保留并尽快清理。多个后端实例通过 PostgreSQL advisory lock 保证同一时间只有一个采集任务执行。

不采集热度时间序列，不永久保留完整历史快照。只保存：

- 当前实体、关系和原始来源指标；
- 当前版本的人气排名、快速跌落点和熟悉度层级；
- 当前活动数据代及最后一次同步状态。

## 原因

单后端降低部署复杂度。活动数据代与同步状态属于保证一致性的运行数据，不用于历史分析，因此不违背“不收集历史数据”的要求。
